# マスタ編集の条件保持と個別削除確認

基点: 0201984。顧客・仕入先の編集画面で、既存の締日・支払条件に一致する選択肢がない場合も、その値を選択肢として保持する。「20日」を「20日締め」へ変換する等の書き換えは行わず、未設定も未設定のまま保存する。過去データの一括更新・DB移行は不要。

個別削除は対象名を表示するネイティブのモーダルダイアログで確認する。最初の「削除」はダイアログを開くだけで、キャンセル・EscapeではDB処理を呼ばない。「削除する」で初めて送信する。送信中は再送・キャンセル・Escapeを抑止する。サーバーでも対象IDに一致する確認値がない削除要求を拒否する。既存の認証・RLSによるアクセス制御は維持する。

回帰テストは顧客／仕入先の実サーバーページとアクションを仮DBで呼び出す。旧表記、任意条件、標準条件、空欄・NULLの表示と他項目変更時の保持、未確認／別IDでの削除拒否、確認後のみ削除、ダイアログの開閉と送信中の操作制御を検証する。実データの削除確定は行わない。
