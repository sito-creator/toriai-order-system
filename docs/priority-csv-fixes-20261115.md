# 商品CSV・銀行CSVの優先修正（2026-11-15）

対象は商品CSV取込と銀行CSVの請求書紐づけ。AI取込・契約書添付は変更しない。

## 商品CSV
画面のサンプル「標準単価」「仕入単価」を認識する。旧列名も対応。
0円と空欄を区別し、不正金額・重複コード・列不足・税率不正は保存前にエラー。
カンマ付き金額・引用符・改行・UTF-8/BOM・Shift_JISを読み取る。
有効FALSEを保持。税率列がない場合は10%。所属会社IDは認証から取得し、旧priceも標準単価と同期する。
全行を検証後に単一INSERT。登録件数を確認し商品一覧とPOS等を再検証する。

## 銀行CSV
同額の請求候補が複数、または同額の入金が複数なら自動選択しない。
手動候補は同額のみ。別行で指定済みの請求書は選択不可。
重複した指定がある場合は画面で確定不可。保存側でも全選択の重複・所属会社・金額・発行状態を検査する。
保存時に状態と金額の比較更新を行い、読み取り後の変更や既に入金済みの請求を成功扱いしない。
複数件の確定は一括トランザクションではなく個別比較更新。途中競合は成功／失敗件数で表示。
異なるアップロード間の銀行取引ID照合や自動重複検出は今回の範囲に含まない。

実際のコンポーネントのファイル選択→カラム設定→自動／手動選択→確定ボタン制御を仮データで確認。
